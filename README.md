# Battle Royale Lite · 吃鸡轻量版（优化）

## 打开

双击 `index.html` 或 `open.bat`（Chrome / Edge）。

## 本版优化

- 休闲难度：8 人机、开局手枪/护甲/医疗、毒圈更慢
- 环境：草地、公路、池塘、树木、房屋细节
- 手感：轻微辅助瞄准、镜头跟枪、自动捡补给、打空自动换弹
- 反馈：音效、枪口火花、脚步尘土、受伤红闪、毒圈方向箭头
- 操作：`M` 开关音效，`Q/E` 医疗包

## 操作

| 键 | 功能 |
|----|------|
| WASD / Shift | 移动 / 冲刺 |
| 鼠标 / 左键 | 瞄准 / 射击 |
| R / F | 换弹 / 拾枪 |
| Q 或 E | 医疗包 |
| 1–4 | 切枪 |
| Esc / M | 暂停 / 音效 |
